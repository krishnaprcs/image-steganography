How the Encoding & Decoding Algorithms Work

1

Password Encryption (AES-256)

When you enter a password, PBKDF2 (100,000 SHA-256 iterations) derives a secret key from your password and a random 16-byte salt. The text is then encrypted with AES-256-GCM so wrong passwords cannot unlock it.

2

LSB Pixel Embedding

A 9-byte header ("STEG" signature + mode flag + byte length) and the payload are converted into bits. Each bit replaces the Least Significant Bit of consecutive Red, Green, and Blue pixel values via (channel & 0xFE) | bit.

3

Extraction & Decryption

During decoding, channel & 1 extracts the header and payload bits from the PNG pixels. If locked, your password decrypts the payload back into readable text — or shows an error if the password is incorrect.
